## Согласовано

- Базовый лимит повторок X по умолчанию 0; это дополнительные копии каждого названия в одном городе. X=1 разрешает одновременно две Таверны и две Дозорные башни, но не третью копию при обычном строительстве.
- X не меняет механику Каменоломни и Волшебника: их существующие исключения сохраняются.
- Флаг Дипломата разрешает обмен с завершённым городом оппонента; по умолчанию выключен.
- Флаг Магистрата по умолчанию выключен. При выключенном флаге конфискация повторок разрешена в пределах X. Разрешение при включённом флаге без ограничения X предложено и требует итогового подтверждения.
- Старые паки без новых настроек получают X=0 и оба флага=false.
- Творец собирает корректный пак для будущего подходящего состава, независимо от текущего состава комнаты. Нарушения структуры, включая нескольких персонажей одного ранга, не разрешаются.
- Включённый режим творца запрещает старт. Он сохраняется только в черновике редактора, без экспорта в пак.
- Редактировать промежуточный набор можно; сохранение/экспорт готового пака требует возможности старта хотя бы при одном допустимом числе игроков от 2 до 8. Причина отказа видна пользователю.
- При выключении режима карты сохраняются; неподходящий состав блокирует старт, а не удаляет карты.
- Импорт Театра при нехватке игроков должен сохранять карту; ограничения состава проверяются перед стартом.
- В левую всплывающую памятку добавить объяснение победы и равенства очков.
- Подготовить лаконичный тест-план будущих проверок: рабочие сценарии, запреты и отсутствие регрессий.

## Предлагаемый текст памятки

Когда кто-либо завершает город, доиграйте текущий раунд, затем подсчитайте итоговые очки. Первый завершивший город не обязательно побеждает. Побеждает игрок с наибольшим итоговым счётом. При равенстве очков сравните сумму номинальных стоимостей построенных кварталов, без украшений и бонусов; фактические расходы на строительство не учитываются. При равной сумме побеждает игрок с большим запасом золота. Если и золота поровну, эти игроки делят победу.

## Проверка готовности пака

Существующая проверка числа разных названий должна учитывать разрешённые повторки и фактическое количество карт, иначе корректный пак с X>0 будет ошибочно отклонён. Проверки раздачи, общего объёма и ограничений персонажей/Театра сохраняются. Для режима творца используется тот же валидатор для каждого допустимого состава 2–8; достаточно одного подходящего состава.

Для статической оценки вместимости города рассматривается сумма min(количество экземпляров, X+1) по строящимся названиям. Тайное убежище не даёт вклад. Монумент требует учёта двойного размера и запрета постройки при пороге 2. Наличие Каменоломни или Волшебника требует сохранить существующее исключение повторок; симуляция всей партии для этой проверки не нужна. Это направление реализации, а не новая игровая способность.

## Предложение реализации для итогового подтверждения

- Общая настройка X — неотрицательное целое число, default 0; флаги Дипломата и Магистрата — false. Удобное название флага Магистрата: «Конфискация сверх лимита повторок», поскольку при выключенном флаге повторки уже разрешены в пределах X.
- Единая проверка повторок оценивает результат конкретной операции, включая исходящие карты при замене/обмене. Уже существующее законное превышение не должно запрещать получение другого названия или уменьшение превышения.
- Общие настройки проходят импорт/экспорт, восстановление черновика и сохранение сетапа начатой партии; отсутствующие поля старых паков и снимков получают прежнее поведение. Сброс базовых настроек возвращает новые игровые параметры к значениям по умолчанию.
- Режим творца хранится отдельно в черновике редактора; блокировка старта проверяется и кнопкой, и обработчиком запуска. Сервер продолжает проверять реальные игровые ограничения. Локальный режим не становится полем правил партии.
