# Эффекты нескольких экземпляров кварталов

Приложение к [общей спецификации](citadels-expansion-spec.md). Пользователь утвердил принцип «один квартал — один эффект» и отдельные ответы Q32–Q35. Таблица конкретизирует его для всех 30 старых особых кварталов; она входит в итоговый апрув всей спецификации, а не описывает текущую реализацию.

N — число экземпляров соответствующего квартала; H — число карт в руке; G — золото; U — число особых кварталов по итоговым типам. Каменный мост не входит в U. Для краткости числовые результаты предполагают достаточный запас карт, иначе действует обычный частичный добор.

| Квартал | Действие экземпляров |
|---|---|
| Тайное убежище | Каждый экземпляр в руке даёт +3 очка в конце игры; строить нельзя. |
| Конюшня | Постройка каждого экземпляра не расходует обычный лимит, но не обходит общий запрет строительства. |
| Квартал призраков | Каждый экземпляр получает свой итоговый тип; выбирается сочетание, максимизирующее общий итоговый счёт. |
| Форт | Каждый экземпляр защищён от персонажей ранга 8; защиты соседним кварталам не даёт. |
| Статуя | Каждый экземпляр даёт +5 очков при наличии короны у владельца в конце игры. |
| Строительные леса | Каждые Леса могут быть пожертвованы для одной постройки; при различающемся состоянии выбирается конкретный экземпляр. |
| Оружейная | Каждый экземпляр может быть пожертвован ради уничтожения одного квартала; выбрать конкретный источник. |
| Обсерватория | Обычный выбор ресурса-карт = 2+N. Башня прорицателя смотрит столько же, но не получает карты. |
| Богадельня | Если перед выплатами конца хода золота нет, каждый экземпляр даёт 1 золотой; выплата первой не отменяет остальные. |
| Монумент | Каждый даёт два в размер города. Проверка запрета последней постройки использует размер города, включая другие Монументы и исключая Катакомбы; действует и для Чертога. |
| Базилика | Каждый экземпляр даёт по 1 очку за каждый квартал нечётной стоимости; существующее влияние украшений на эту стоимость сохраняется. |
| Музей | Каждая постройка имеет свою экспозицию и раз за ход принимает одну карту; очки — сумма размеров всех экспозиций. |
| Каменоломня | Разрешение строить повторки действует уже при одном экземпляре; дополнительные не создают иного числового бонуса. |
| Башня слоновой кости | +5 только для единственного особого квартала; при двух Башнях условие не выполнено ни у одной. |
| Колодец желаний | Каждый даёт по 1 очку за каждый особый квартал, включая себя и другие Колодцы; общий бонус N×U. |
| Фабрика | Каждый уже построенный экземпляр снижает плату за другой особый квартал на 1; минимум общей платы 0. Новая Фабрика не удешевляет собственную постройку, старые удешевляют её. |
| Зал картографии | Каждый даёт по 1 очку за карту в руке: общий бонус N×H. Экспозиции Музеев не входят в руку. |
| Капитолий | Каждый даёт +3 при наличии хотя бы трёх кварталов одного типа; выполнение условия несколькими тройками не умножает бонус одной карты. |
| Некрополь | Каждый строящийся экземпляр может оплачиваться жертвой одного квартала; построенный Некрополь не получает повторяемой способности. |
| Имперская казна | Каждый даёт по 1 очку за золотой: общий бонус N×G. |
| Кузница | Каждая раз за ход за 2 золотых даёт до 3 доступных карт; активации и оплата независимы. |
| Лаборатория | Каждая раз за ход позволяет сбросить отдельную карту руки и получить 2 золотых. |
| Школа магии | Каждый экземпляр даёт один дополнительный подходящий источник цветового дохода персонажа, не меняя постоянный/итоговый тип. |
| Воровское логово | Способ альтернативной оплаты относится к конкретной строящейся карте; уже построенные копии не удешевляют другие постройки. |
| Театр | Прямое копирование запрещено, но карта Театра копируется в экспозиции Музея. Каждый построенный Театр даёт самостоятельный обмен после выбора персонажей; владельцы идут в фактическом порядке выбора персонажей, экземпляры одного владельца подряд. Можно отказаться, таймер пропускает текущий экземпляр. |
| Драконьи врата | Каждый экземпляр даёт +3 дополнительных очка. |
| Парк | Если перед выплатами конца хода рука пуста, каждый даёт до 2 карт; добор первого не отменяет остальные. |
| Великая стена | Каждая добавляет +1 к применимому действию персонажа ранга 8 против квартала этого города, включая саму Стену. |
| Библиотека | Разрешает сохранить весь обычный взятый набор; несколько экземпляров не создают дополнительного добора или копий карт. |
| Золотая шахта | Выбор золота даёт 2+N золотых. |

Условия выплат окончания хода определяются до начислений по одному исходному состоянию. Поэтому Богадельни, Парки и подходящие Ремесленные дворы не отменяют друг друга порядком применения. При уничтожении/получении/копировании источника учитывается состояние конкретного экземпляра, а не заранее выданное число активаций без связи с картами.

При копировании Музея содержимое создаётся самостоятельными объектами по явному решению пользователя. Это разрешённое увеличение числа карт, не ошибка сохранности. Не следует заменять его только визуальными очками или общими ссылками на экспозицию оригинала.

Основание: исследованы все 30 изображений public/cards/*.jpg и код module.js (подсчёт очков, доход, строительство, завершение хода и действия кварталов). Числовое сложение отличается от текущих проверок наличия вида через include/some; требуется согласованное изменение сервера, клиента и сохранений.
