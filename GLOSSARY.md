# Цитадели

Термины партии, используемые при обсуждении правил кварталов и персонажей.

## Language

**Ход**:
Период действий одного персонажа. У одного игрока может быть несколько ходов в одном раунде, если он играет несколькими персонажами.
_Avoid_: Раунд, когда речь идёт о действиях одного персонажа.

**Раунд**:
Цикл, включающий выбор персонажей и последовательные ходы выбранных персонажей.
_Avoid_: Ход, когда речь идёт о полном цикле выбора и действий персонажей.

**Город**:
Совокупность кварталов, построенных у конкретного игрока.

**Рука**:
Карты кварталов, находящиеся у игрока и ещё не построенные в его городе.

**Номинальная стоимость**:
Указанная на карте стоимость квартала до применения скидок и способов оплаты.
_Avoid_: Плата за строительство, когда речь идёт о номинале.

**Плата за строительство**:
Количество золота, которое игрок должен заплатить за постройку квартала с учётом скидок и выбранного способа оплаты.
_Avoid_: Номинальная стоимость, когда речь идёт о фактической оплате.

**Источник цветового дохода**:
Единица своего типа кварталов, учитываемая при получении ресурсов по этому типу. Количество источников дохода может отличаться от количества построенных кварталов.

**Повторка**:
Дополнительный экземпляр квартала с тем же названием, уже имеющимся в городе игрока.
_Avoid_: Повторная постройка, если имеется в виду восстановление ранее разрушенного квартала.

**Базовый лимит повторок**:
Разрешённое обычными правилами число дополнительных копий каждого названия в одном городе. При лимите X город может содержать до X+1 копий каждого названия; отдельные способности могут давать исключения.

**Режим творца**:
Режим подготовки корректного пака для будущего подходящего состава игроков, в котором запуск партии запрещён.

**Размер города**:
Количество кварталов, засчитываемое для завершения города. Может отличаться от числа физических карт построек.

**Выдержка квартала**:
Накопленное время существования постройки, измеряемое завершениями раундов.

**Копирование квартала**:
Создание самостоятельного экземпляра выбранного квартала с его свойствами и состоянием.
_Avoid_: Передача, когда исходный квартал остаётся у своего владельца.

**Передача квартала**:
Перемещение существующей постройки из города одного игрока в город другого.
_Avoid_: Копирование, когда дополнительный экземпляр не создаётся.

**Бесцветный квартал**:
Квартал, который не относится ни к одному игровому типу.

**Фон партии**:
Общее фоновое изображение игры для всех игроков и наблюдателей, выбранное хостом при настройке партии. Для партии выбирается один фон.
_Avoid_: Личный фон, когда речь идёт об общем оформлении партии.

**Стандартный фон**:
Исходный фон игры, доступный для выбора наряду с дополнительными фонами и выбранный по умолчанию.
