# Citadels Web

Веб-версия «Цитадели Делюкс». Пакет игры подключается к отдельному хосту `ws-server-engine`.

## Локальный запуск (Windows, Linux, macOS)

Нужны Node.js с npm, Git и доступ к приватному репозиторию `xdghcnt/ws-server-engine`. Запуск проверен с Node.js 24.21.0. Авторизуйте Git через менеджер учётных данных; примеры ниже не содержат токенов.

Расположите репозиторий игры и папку хоста рядом:

```text
Code/
├── citadels-web/
└── meme-police/
```

Создайте в `meme-police` файл `package.json`:

```json
{
  "name": "meme-police-local",
  "private": true,
  "scripts": {
    "start": "node app.js"
  },
  "dependencies": {
    "ws-server-engine": "git+https://github.com/xdghcnt/ws-server-engine.git#9c4a28352e7f1ad8df53f571ae37854616cdfbf4",
    "citadels": "file:../citadels-web"
  }
}
```

Ревизия движка закреплена для воспроизводимости. Если папка игры называется иначе, измените путь `file:../citadels-web`. При авторизации через SSH замените адрес движка на `git+ssh://git@github.com/xdghcnt/ws-server-engine.git#9c4a28352e7f1ad8df53f571ae37854616cdfbf4`.

Создайте в `meme-police` файл **`app.js`**:

```js
const port = Number(process.env.PORT || 3000);
const wsServer = new (require("ws-server-engine"))(
    process.env.MANAGE_KEY || "local-development-key",
    {
        port,
        origin: process.env.ORIGIN || `http://localhost:${port}`,
        appDir: __dirname,
        timeZoneOffset: 3,
        rateLimit: {time: 1, amount: 10, blockDuration: 5},
        maxConnections: 20,
        maxRoomsPerIP: 3,
        maxUsersPerRoom: 25,
        maxPayload: 10000,
        dumpInterval: null,
        pingInterval: 60000 * 15,
        inactivityTimeout: false,
        updatesVersion: 1
    }
);

wsServer.users.restoreManagedRooms().then(() => {
    require("citadels")(wsServer, "/bg/citadels", "");
}).catch(console.error);
```

Это конфигурация для локальной разработки. Ключ управления можно задать переменной `MANAGE_KEY`.

Из папки хоста установите зависимости и запустите сервер; команды одинаковы для PowerShell и оболочек Linux/macOS:

```sh
cd ../meme-police
npm install
npm start
```

После сообщения `WS-registry started` откройте [игру в локальной комнате](http://localhost:3000/bg/citadels#local-test). Нужен путь `/bg/citadels`: корень сайта `/` игру не запускает. Часть после `#` — идентификатор комнаты.

Для проверки партии откройте тот же адрес во втором профиле браузера или приватном окне, задайте разные имена и займите места. Настройки игры доступны через шестерёнку и кнопку запуска. В отдельном хосте панель обновлений `/bg/updates` может отвечать 404; её можно закрыть.

Для другого порта в PowerShell:

```powershell
$env:PORT = "3001"
npm start
```

В Linux/macOS:

```sh
PORT=3001 npm start
```

Адрес игры тогда — `http://localhost:3001/bg/citadels#local-test`. Если используется другой хост, задайте `ORIGIN` соответствующим URL, включая порт.

## Особенности WSL

Выполняйте установку и запуск внутри одного окружения. Для WSL установите Linux-версию Node.js с npm и храните обе папки рядом, например в `~/Code`. Проверьте инструменты в терминале Ubuntu:

```sh
command -v node
command -v npm
node -p process.platform
```

Ожидается `linux`; пути не должны вести к Windows-установке под `/mnt/c`. Не смешивайте Windows `npm install` и Linux-запуск: локальная зависимость игры использует ссылку на соседнюю папку.

```sh
cd ~/Code/meme-police
npm install
npm start
```

Сначала проверьте сервер из WSL:

```sh
curl -I http://localhost:3000/bg/citadels
```

Если из Windows не открывается `localhost`, при работающем сервере получите адрес WSL командой `hostname -I` в Ubuntu и попробуйте `http://<IP-WSL>:3000/bg/citadels#local-test`. Адрес WSL может измениться после перезапуска. При использовании IP задайте `ORIGIN` этому адресу перед запуском.

Для режима NAT настройка перенаправления localhost находится в `%USERPROFILE%\.wslconfig` на Windows:

```ini
[wsl2]
localhostForwarding=true
```

После изменения конфигурации выполните `wsl --shutdown` из PowerShell и заново запустите Ubuntu и сервер. Команда остановит все текущие дистрибутивы WSL. Эта настройка относится к перенаправлению портов; предупреждение о Windows-прокси на localhost — отдельная настройка сети, она сама по себе не подтверждает ошибку сервера.

## Разработка и тесты

Тесты запускаются из **папки игры** и не требуют установки движка:

```sh
cd ../citadels-web
npm test
```

Используется встроенный тестовый раннер Node.js. Проверяются формат настроек, ограничения и совместимость JSON, раздача, добор и сброс, серверные сценарии и восстановление сохранений.

Отдельной сборки нет: JSX компилируется в браузере. После изменения `public/app.jsx`, HTML или CSS обновите страницу. После изменений `module.js`, `utils.js` или общего `public/setup.js` перезапустите сервер; для `setup.js` также обновите страницу. Зависимость `file:` подключает рабочую папку игры, копировать её вручную не нужно.

Пять готовых JSON-наборов, краткие сценарии повторных проверок и запуск двух автоматизированных браузерных тесткейсов находятся в [autotests](autotests/README.md).

## Настройки партии

Экспорт сохраняет базовую колоду, выбранные особые кварталы, персонажей, таймер и новые секции формата `citadels-setup` версии 1:

```json
{
  "starting": {
    "handSize": 4,
    "minUnique": 0,
    "gold": 2,
    "exactUnique": false,
    "firstCrownReduction": {"cards": 0, "gold": 0}
  },
  "rules": {
    "citySize": null,
    "bonuses": {"firstCity": 4, "otherCities": 2, "allColors": 3},
    "preventRepeatedRandomDiscard": false
  }
}
```

Это фрагмент файла; полный файл создаёт кнопка «Экспорт». Отсутствующие в старых файлах секции получают значения по умолчанию. `citySize: null` означает 8 кварталов для троих и 7 для остальных составов от 2 до 8 игроков; ручное значение допускается от 2 до 10. Минимум особых гарантируется каждому игроку, если колода позволяет раздачу. Галочка «Фиксированное число» (`starting.exactUnique: true`) задаёт ровно указанное число особых каждому: остальные карты руки берутся только из базовой колоды. Если базовых или особых не хватает, начать игру нельзя. В старых файлах без `exactUnique` сохраняется режим минимума. Базовая колода, стартовые ресурсы и завершение города находятся под общим спойлером «Расширенные настройки». Несовместимые с составом персонажи остаются выбранными после импорта и блокируют старт с пояснением.

Первый владелец короны определяется случайно до раздачи. `firstCrownReduction` уменьшает только его стартовые карты и золото; невыданные карты остаются в колоде. Уменьшения — целые неотрицательные числа, не превышающие исходные ресурсы. Минимум или фиксированное число особых применяется и к уменьшенной руке: например, минимум 1 при нулевой руке короны недопустим.

`rules.bonuses` задаёт три независимых бонуса: полный бонус первому завершившему город, бонус остальным завершившим и бонус за все пять цветов. Допускаются целые неотрицательные числа; ноль отключает соответствующий бонус. Первый завершивший сохраняет весь свой бонус, даже если затем жертвует Арсеналом и уменьшает город. Остальные получают бонус только за город, достигший нужного размера на момент подсчёта. `preventRepeatedRandomDiscard` запрещает случайно сбрасывать того же персонажа в двух соседних раундах. Учитываются открытый, закрытый и дополнительный случайный сброс для троих; ручной сброс в дуэли и способности персонажей этим правилом не ограничены. История случайного сброса хранится только на сервере и восстанавливается вместе с партией.

Сохранения партий из версии до появления сетапа продолжают работать с прежней колодой и порогом города. Если исходные настройки не были сохранены, просмотр сообщает об этом; настройки следующей партии не выдаются за настройки уже начатой.

Настройки, импорт и экспорт доступны хозяину комнаты. Последний корректный черновик формы сохраняется только в браузере, в `sessionStorage`, отдельно для комнаты и пользователя. Он переживает F5 в той же вкладке и хранится до завершения её сессии, без дополнительного срока действия. Повреждённый черновик удаляется при чтении, редактор использует стандартные настройки. При недоступном хранилище форма продолжает работать без сохранения. Незавершённый некорректный ввод может потеряться.

Редактирование формы не отправляет сообщений серверу. Он проверяет и сохраняет итоговый сетап только при запуске партии. Игроки и наблюдатели получают его отдельным событием `game-setup` при входе/переподключении и при начале новой игры; обычные события `state` не содержат сетап или черновик. До первой партии просмотр сообщает, что настройки ещё недоступны; после окончания показывает сетап последней начатой партии. Менять его могут только хозяин и только через запуск новой партии с прошедшими проверку настройками.

Под настройками времени хозяин выбирает один фон партии: стандартный или дополнительный из каталога. Выбор сохраняется в `sessionStorage` отдельно от сетапа, для текущего пользователя и комнаты; импорт и экспорт JSON его не меняют. Фон применяется для всех игроков и наблюдателей при успешном старте и остаётся в лобби после окончания. Он сохраняется в снимке комнаты и передаётся как `backgroundId` в публичном `state`; старые снимки используют стандартный фон. Изображение заполняет окно без повторов и искажения пропорций, с обрезкой краёв. В просмотрщике сетапа выбор фона не отображается.

Источники дополнительных фонов: [The Waterfront — Hakob Minasian](https://hakobminasian.artstation.com/projects/k2ga6), [Waterfall Castle — Dejan Mijatovic](https://www.behance.net/gallery/63484609/Waterfall-Castle), [Island castle](https://backiee.com/wallpaper/island-castle/277136).

Сброшенные и разрушенные кварталы образуют отдельную закрытую стопку. Когда колода заканчивается, сброс перемешивается и становится новой колодой. Игроки и наблюдатели видят только количества карт в обеих стопках. Наведение, фокус клавиатуры или нажатие на иконки счётчиков открывает рядом пояснение; карты в руках, городах и на выборе в эти количества не входят.


## Расширение кварталов и настройки повторок

Добавлены 14 кварталов расширения. Стандартный состав колоды сохранён; новые карты выбираются явно. Каменный мост не имеет игрового типа и выбирается в списке с особыми картами, Дом заговорщиков доступен при 4–8 игроках.

В формате сетапа v1 появились необязательные поля rules.duplicateLimit (дополнительные копии каждого названия, по умолчанию 0), rules.diplomatCompleteCity и rules.magistrateOverLimit (по умолчанию false). Старые JSON получают эти значения автоматически. Режим творца сохраняется только в локальном черновике; он запрещает старт и позволяет экспортировать пак, пригодный хотя бы для одного состава игроков.

Постоянная скидка хранится на экземпляре карты отдельно от номинала. Состояние построек и отложенные действия сохраняются в snapshots. Серверный подсчёт очков вынесен в district-scoring.js; этот файл входит в пакет наряду с module.js и utils.js. При обновлении хоста нужно поставить весь пакет и перезапустить сервер.

Барахолка (`flea_market`) — отдельный новый особый квартал стоимостью 2, доступный по явному выбору в настройках. Стандартная колода по-прежнему содержит 65 карт; D10 «Семинария» и D11–D14 не перенумерованы. Раз за свой ход каждый построенный экземпляр бесплатно обменивает одну карту руки на верхнюю карту колоды: сначала сбрасывает выбранную карту, затем добирает. При пустой колоде только что сброшенная карта участвует в перемешивании сброса и может сразу вернуться.
