# Наборы для повторных проверок

Каждый JSON импортируется через меню игры. Наборы используют `citadels-setup` v1; таймер выключен, чтобы проверки не зависели от скорости действий. Количество игроков задаётся комнатой.

| Набор | Игроков | Необходимые проверки |
|---|---:|---|
| [01-legacy-defaults.json](01-legacy-defaults.json) | 4 | Старый файл без `starting` и `rules`: рука 4, золото 2, минимум особых 0, город 7, бонусы 4/2/3, уменьшения короны 0/0, запрет случайного повторного сброса выключен. Всего 65 карт; после старта колода 49, сброс 0. Экспорт и повторный импорт сохраняют значения. |
| [02-exact-one.json](02-exact-one.json) | 4 | У первой случайной короны 3 карты и 1 золото, у остальных 4 карты и 2 золота; всем ровно 1 особая. В колоде 50, сброс 0. Бонус первому 6, остальным 2, разноцвет отключён. Случайные сбросы соседних раундов не пересекаются. Все новые поля сохраняются при экспорте/импорте. |
| [03-short-duel.json](03-short-duel.json) | 2 | На старте 4 базовых каждому, в колоде 2 особых, сброс пуст. Обычный добор: выбрать одну из двух → колода 0, сброс 1. Следующий добор возвращает единственную карту из сброса; затем пустой выбор не открывается, монеты доступны. Город из 2 кварталов завершает игру в конце раунда. |
| [04-restricted-characters.json](04-restricted-characters.json) | 2 → 5 | При двух игроках Император и Королева остаются выбранными, старт запрещён с двумя понятными причинами. Заменить Императора Королём и снять Королеву → старт разрешён. Повторно импортировать исходный файл при пяти игроках → старт разрешён без замены персонажей. |
| [05-one-basic-short.json](05-one-basic-short.json) | 4 | Всего 22 карты, но для точной раздачи не хватает одной базовой: требуется 12, есть 11. Уменьшить руку короны на 1 → старт разрешён. Уменьшить на 4 → отказ: особый квартал не помещается в нулевую руку короны. Уменьшить на 3 → у короны ровно 1 особая карта, у остальных по 4. Альтернатива исходному паку: увеличить Рынок с 3 до 4 или снять галочку → старт разрешён. |

Общее для наборов: считать реальные карты в руках, колоде и сбросе; не проверять случайный порядок. Второй клиент и наблюдатель видят сетап начатой партии без полей редактирования, импорта и экспорта. Черновик хозяина до старта им не передаётся. При старте, F5 или позднем входе появляется актуальный сетап; обычные игровые обновления его не пересылают. Проверять одинаковые счётчики и пояснение рядом при наведении или фокусе.

Для интерфейса достаточно набора 02 на 1280×600 и 390×844: заголовок спойлера по центру, подсказка справа и внутри экрана, импорт/экспорт справа внизу секции. Запрет повторного случайного сброса расположен под базовой колодой. Вторая кнопка «По умолчанию» находится после бонусных очков внутри спойлера и сбрасывает стартовые ресурсы, уменьшения первой короны, размер города и бонусы. Колода, персонажи, таймер и запрет повторного сброса сохраняются.

Браузерные раннеры сохраняют скриншоты и журналы в отдельную папку системного временного каталога. Полный путь выводится при запуске как `Test artifacts: ...`. Чтобы выбрать другую папку, задайте `CITADELS_TEST_OUTPUT`.

## Два автоматизированных браузерных сценария

[ui-party-settings.cjs](ui-party-settings.cjs) создаёт новые комнаты и отдельные профили браузера:

1. Нулевая рука короны при минимуме 1 запрещает старт; после исправления экспорт/импорт сохраняет новые поля. При старте корона получает 1 карту и 0 золота, второй игрок — 4 карты и 2 золота, обоим ровно по 1 особому. Колода сохраняет все невыданные карты. Просмотр сетапа хостом на широком и мобильном экране не содержит персонажей и строк уменьшения ресурсов короны; итоговые ресурсы первой короны видны. Скриншоты сохраняются в `setup-viewer-host*.png` в папке результатов.
2. Форма работает со старым HTML без отдельного скрипта хранения и без ошибок JavaScript. Редактирование не отправляет WebSocket-сообщений; черновик хозяина восстанавливается после F5. До первой партии игрок и наблюдатель видят сообщение об отсутствии сетапа. При старте, перезагрузке игрока и позднем входе наблюдателя они получают итоговые настройки без возможности редактирования. Мобильное окно и подсказка счётчиков остаются внутри экрана, количества совпадают у клиентов. Срок жизни сессии без TTL, изоляция по комнате/пользователю и ошибки браузерного хранилища проверяются юнитами.

Зависимости соседнего хоста `meme-police` должны быть установлены по инструкции в основном README. Из папки игры запустите отдельный тестовый хост:

```sh
node autotests/ui-host.cjs
```

В другом терминале установите CLI и запустите сценарии:

```sh
npm install --no-save --package-lock=false @playwright/cli@0.1.22
node autotests/run-ui.cjs node_modules/@playwright/cli/playwright-cli.js http://localhost:3002
```

Если CLI установлен в другом месте, передайте путь к его `playwright-cli.js` первым аргументом. Для браузера нужен установленный Chrome. Результат сохраняется в `party-settings-result.txt` в папке результатов; успешный запуск содержит `CASE 1 PASS` и `CASE 2 PASS`. Ошибка любого сценария даёт ненулевой код завершения.

Для запуска хоста из WSL с браузером Windows при недоступном localhost задайте `ORIGIN=http://<IP-WSL>:3002` и передайте тот же адрес раннеру. Тестовый хост использует отдельную временную папку данных; обычный хост и его комнаты не затрагиваются. После проверки остановите тестовый хост через Ctrl+C.

## Выбор фона без движка

`ui-backgrounds.cjs` проверяет настоящий React-редактор и обработчик публичного состояния в Chrome, с заглушкой транспорта комнаты. Требуются Playwright, Chrome и каталог зависимостей с React/ReactDOM 16–18 (UMD), `@babel/core`, `@babel/preset-react`. Установка движка для этой проверки не нужна:

```sh
node autotests/ui-backgrounds.cjs /path/to/playwright/node_modules /path/to/frontend/node_modules
```

Проверяются все миниатюры каталога под таймером, единственный выбор, отсутствие сообщений при редактировании и загрузки больших дополнительных фонов до старта, восстановление после F5, ширины 390 и 320 пикселей, ID в запросе старта, применение через публичный `state`, `cover` без повторов и сохранение фона в лобби. Скриншоты — `background-picker-*.png` в папке результатов, успешный результат — `BACKGROUND UI PASS`. Скрипт останавливает только собственный временный HTTP-сервер и браузер.

Серверные права, отказ старта без мутации, сохранения, поздний вход и совместимость старых снимков проверяются в `test/start-game.test.js`. Импорт JSON без сброса выбранного фона и сохранение выбора при незавершённом числовом вводе — в `test/setup-client.test.js`. Эти проверки не заменяют полный сценарий с настоящим `ws-server-engine`.

## Превращение Зеркального чертога без движка

`ui-mirror-animation.cjs` проверяет настоящие `Game`, `PlayerSlot` и `Card` в Chrome с заглушкой транспорта. Нужны Playwright, Chrome и React/ReactDOM 16–18 (UMD), `@babel/core`, `@babel/preset-react`:

```sh
node autotests/ui-mirror-animation.cjs /path/to/playwright/node_modules /path/to/frontend/node_modules
```

Проверяются исходная карта и переход длительностью 2600 мс, затемнение и блики, обычные и полноформатные JPEG-карты, отсутствие повтора при обновлении состояния и сдвиге индексов города, увеличение карты с продолжением текущей фазы, ширины 390 и 320 пикселей, очистка после `animationend`, режим уменьшения движения, F5 и наблюдатель. Результаты — `mirror-animation-proof.json` и `mirror-*.png` в папке результатов. Скрипт останавливает только свой временный HTTP-сервер и браузер.

Успешная постройка копии обычным способом или через Кардинала отправляет одноразовый `mirrorBuild` в публичном `state`. Сигнал не сохраняется в `room`/snapshot; обычное строительство без копирования, отказ, поздний вход и восстановление снимка не запускают эффект. Серверные сценарии и жизненный цикл клиента проверяются отдельно:

```sh
node --test test/district-actions.test.js test/mirror-animation-client.test.js
```

Это компонентная браузерная проверка, а не полный сценарий хоста `ws-server-engine`.

## Барахолка без движка

`ui-flea-market.cjs` проверяет настоящий интерфейс `Game`, карты руки, кнопки выбора и подтверждения в Chrome с заглушкой транспорта комнаты:

```sh
node autotests/ui-flea-market.cjs /path/to/playwright/node_modules /path/to/frontend/node_modules
```

Нужны те же Playwright, Chrome и React/ReactDOM 16–18 (UMD), Babel. Сценарий проверяет выбор ровно одной карты, замену/снятие выбора, отмену без сетевого события, одно событие после подтверждения, выбор Тайного убежища при запрете строительства и пустых стопках, недоступность при пустой руке, сброс устаревшего выбора через публичные и закрытые обновления, ширины 390 и 320 пикселей. Дополнительно проверяет подключение принятого JPEG из настоящего каталога, прямое изображение карты, увеличение и галерею; свойства каталога в тесте не подменяются. Результат — `FLEA MARKET UI PASS`, скриншоты и `flea-market-ui-proof.json` в папке результатов. Раннер закрывает только собственные сервер и браузер.

Серверный порядок сброса/добора, права, экземпляры, перенос/копирование, снимки и скидки проверяются отдельно:

```sh
node --test test/flea-market.test.js test/client-expansion.test.js
```

Это компонентная проверка с заглушкой транспорта, а не полный прогон хоста `ws-server-engine`.
